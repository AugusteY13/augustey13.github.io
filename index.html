Aethelgard

Type : Bot Discord

Problème : Les administrateurs d'un serveur souhaitent transférer l'ensemble de leurs contenus RP vers un nouveau serveur, sans perdre l'historique des échanges déjà réalisés.

Solution : Développement d'un bot capable d'enregistrer les messages d'un salon, puis de les retransmettre automatiquement dans un autre salon.

Server Designer

Type : Bot Discord

Solution : Développement d'un bot permettant d'automatiser entièrement la création de la structure d'un serveur à partir d'un simple fichier texte décrivant les différents éléments à générer.
